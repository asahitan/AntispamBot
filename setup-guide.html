Setup guide

Last updated November 23, 2026.

This guide walks you through adding Antispam to a Discord server and switching on your first protections. It takes about five minutes. For a full description of every feature, see the features documentation.

1. Add the bot and check its role

Use the invite link and choose the server you manage. After the bot joins, open Server Settings, go to Roles, and drag the Antispam role to the top of the list. Antispam can only punish, rename or give roles to members whose highest role is below its own, so a low role is the most common reason a feature seems to do nothing.

2. Open the dashboard

Run /configure in any channel. The dashboard is only visible to you and needs the Administrator permission. The Overview shows how each feature is set up, a gray circle for features that are not in use, and a Needs attention list for problems such as missing permissions or role order errors.

3. Turn on Anti-Spam

In /configure, choose Anti-Spam and set it up in this order:

  • Choose a punishment. Kick, Ban, Delete Message, Timeout or Warn. One is required before anti-spam can be enabled.
  • Set the spam limit. This is how many messages a member can send (1 to 5, default 5) within a number of seconds (3 to 30, default 10). With 3 messages and 5 seconds, a member can send 3 messages in 5 seconds and the 4th is punished.
  • Choose a log channel so you can see what was caught.
  • Press Enable. Your choices are not saved until you do.

Administrators and whitelisted roles or members are never checked, so test with a normal member account.

4. Add more layers

Each feature works on its own, so turn on only what your server needs:

  • Duplicate Filter deletes repeated and near-identical messages.
  • Spam Filters catch mass mentions, emoji spam, excessive caps, walls of text and more. They all start switched off, and each has a log-only (dry run) mode for testing your limits without punishing anyone.
  • Scam Link Detection finds phishing and fake-giveaway links by judging the address itself.
  • Link Notifier logs every link and can delete the ones you do not want.
  • Filter Words blocks the words and phrases you choose.

5. Protect against raids

  • CAPTCHA Verification makes new members pass a check before they can talk.
  • Honeypot is a trap channel. Anyone who posts in it is sanctioned automatically, which catches hacked accounts and spam bots.
  • New-Member Gate, Raid Shield, Guard and Anti-Bot are for the server owner and any co-owners the owner chooses. Each is off until one of them turns it on.

Two example setups

These are starting points, not requirements.

  • Small community: Anti-Spam with the Warn punishment, Warn Escalation steps such as 3 warnings for a timeout, 5 for a kick and 7 for a ban, Appeals for fairness, and a log channel for staff.
  • Large public server: CAPTCHA for every new member, the New-Member Gate with an account age limit, Raid Shield, Guard with your real admins on its trusted list, a Honeypot channel, and Spam Filters in log-only mode first.

Check that it works

Run /antispam status, /guard status, /shield status and the other status commands to confirm each feature is on and nothing is missing. Then open the Overview in /configure and clear anything under Needs attention.

Troubleshooting

  • Nothing happens when a member spams. Check that the Antispam role is above the member, that a punishment is set, and that you are not testing with an administrator or whitelisted account.
  • Too many false positives. Raise the limits, whitelist trusted roles, switch a filter to log-only, and use the Pardon button on the log message to undo a mistake in one click.
  • Still stuck. Ask in the support Discord server or email antispamdevs@gmail.com.
